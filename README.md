# Kaiju Melee — downloads

**New players:** download [KaijuMelee_PCVersion.zip](https://github.com/Ozyman515/kaiju-melee-releases/raw/main/KaijuMelee_PCVersion.zip),
unzip it anywhere and run `KaijuMelee.exe` (Windows, 64-bit).

**Already playing:** updates install from the title screen (INSTALL UPDATE, then RESTART TO UPDATE).

This repository only holds the releases. `manifest.json` describes the newest build and is signed
(`manifest.sig`) with the release key; the game refuses any update without a valid signature.
